# Another House design rules

## Multi-page appliance diagrams

- Start with official manufacturer documentation whenever it exists.
- Include the complete operating sequence, not only the control-panel illustration.
- Remove pages that do not help a guest operate the appliance, such as power-wiring or installation-only pages.
- Render two or more diagram pages as one horizontal, touch-scrollable carousel.
- Keep the next page partially visible on the right so the swipe interaction is immediately obvious.
- Use scroll snapping and a visible page counter.
- Korean mode uses Korean diagrams. English, Japanese, and Chinese modes use official diagrams for that language when available, otherwise English.
